F5  PREIS-REFERENZ TP1/TP2 BEI KANTE k-1  =>  BINDUNG AN vz_prev (k-1)
---------------------------------------------------------------------
    EINE Zonen-Referenz vz_ref = _laufende_zone(df, p, k-1) fuer:
      - Touch-Test (hi[k] >= vah_prev / lo[k] <= val_prev)
      - Ziel-Geometrie: tp1 = POC_prev, tp2 = val_prev*(1+puffer) bzw.
        vah_prev*(1-puffer)
      - Gueltigkeit entry > POC_prev (SHORT) / entry < POC_prev (LONG)
      - strukturelle RR: e_preis > tp2_prev (SHORT) / e_preis < tp2_prev
    Begruendung:
      - Deterministische RR-Geometrie: Touch, Gueltigkeit und Ziele stammen
        aus EINEM Snapshot, der VOR der Signal-Bar stand. Der institutionelle
        Haendler reagiert auf ein STEHENDES Level.
      - Mischung (Touch k-1 / Ziele k) waere ein Snapshot-Artefakt: Bar k
        verschiebt POC/VAH/VAL durch ihr eigenes Volumen -> Bar k wuerde
        sich selbst guenstigere Ziele "belohnen".
      - Technisch: eine Zonen-Berechnung je Bar statt zwei.
    Index-Sicherstellung (Schritt 1):
      - k-1 >= p.i_start Guard (leerer Praefix i_start..k-1 -> skip)
      - min_zone_candles auf den vz_prev-Praefix: Zone bis k-1 hat
        k - i_start Bars -> Bedingung: k - p.i_start >= min_zone_candles
        (Scan startet damit eine Bar spaeter als im Status quo, Z. 926).
      - range(p.i_start, p.i_ende) exklusiv -> letzter Scan k = i_ende-1,
        vz_prev endet bei i_ende-2 -> Snapshot strikt INNERHALB der Phase,
        kein Grenz-Leak. Einstieg open k+1 unveraendert.
